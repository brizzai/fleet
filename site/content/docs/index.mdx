## What fleet is

fleet goes deep on Claude Code instead of supporting every agent CLI. It reads hooks for real-time status, captures the session ID for `claude --resume`, knows your PR has 2 unresolved review threads, and titles sessions from your first prompt.

If Claude Code is your daily driver, this is the tightest integration on the market.
