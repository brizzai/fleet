**Reopen a closed session.** `U` (or `Ctrl+K` → "Reopen Last Closed Session") brings back the session you just deleted, resuming the same conversation in the same folder and Claude account — the last 20 are remembered across restarts, not just for the 5s `u` window.

**Closing live work asks for `y`.** Deleting a session that is running or waiting on a prompt now needs an explicit `y`; `Enter` declines, so a reflexive keypress can't kill a turn in flight.
