**The diff reader reads like a diff.** Code in the review reader (`c` → `⏎`) now has syntax colours, and added/deleted rows carry a tinted background instead of green and red text — so on a changed line only the words that actually changed light up. Wide terminals get side-by-side automatically (`|` toggles), `/` searches, and `⏎` on a `⋯ 31 lines hidden` fold pulls the surrounding code straight out of the review worktree with no round trip to GitHub.
