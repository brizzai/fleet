**Two Claude subscriptions, one fleet.** Add a second account with `Ctrl+K` → "Manage Claude Accounts" and each new session runs on whichever account has more headroom, so one spent 5-hour window no longer stalls every session. Restarting a session whose account is spent or whose token stopped working moves it to one that works, and `.` → "Move to Account…" moves any session by hand. A top-right readout alternates between each account's 5-hour and weekly usage.
