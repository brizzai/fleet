**Two Claude subscriptions, one fleet.** Add a second account with `Ctrl+K` → "Manage Claude Accounts" and each new session runs on whichever account has more headroom, so one spent 5-hour window no longer stalls every session. A top-right readout tracks each account's weekly usage, and "Move to Next Account" shifts a stuck session across without losing its conversation.
