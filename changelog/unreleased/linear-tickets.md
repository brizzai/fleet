**Start a worktree from a Linear ticket.** Type `BRZ-3182` in the `w` dialog — or search by words — and fleet names the branch from the ticket, writes it and its screenshots into the worktree, and opens the agent already told to read it and not start yet. Existing worktrees whose branch names a ticket get the same treatment, and `fleet wt --ticket BRZ-3182` does it from the shell. Screenshots reach the agent even on a `linear` CLI too old to download them.
