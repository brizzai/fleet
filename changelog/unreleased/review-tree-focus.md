**Jump straight to a file in a review.** `⇥` in the diff reader moves the keyboard to the file tree, where `↑↓` picks a file and the diff follows along — the same relationship the session list and preview already have. Fold a directory away with `⏎` or `←`, `⏎` on a file hands the keyboard back, and the accent border always shows which panel you're driving. The tree always names the file the diff is showing, whichever panel you moved.
